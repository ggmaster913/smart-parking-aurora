# Умная парковка для ОС Аврора

Команда **ИИксперты**, хакатон «Ночь кода», 7–8 ноября 2026 года.

Прототип: профиль и автомобиль, поиск парковки на карте, выбор места, симуляция оплаты, электронный талон и продление парковки. Данные хранятся локально, парковки симулируются.

## Текущее состояние

Создан репозиторий и зафиксированы требования, контракты и процесс работы. **Приложение ещё не собрано и не запущено.** Первый технический рубеж — импортировать проект из настоящего шаблона SDK и подтвердить запуск в эмуляторе. Наличие документации не означает завершение функционального этапа.

## С чего начать участнику

1. Принять приглашение в репозиторий и прочитать [AGENTS.md](AGENTS.md).
2. Передать своему Claude Code [единый промпт настройки](docs/SETUP_PROMPT.md).
3. Найти своё назначенное issue. Работать в отдельной ветке, открыть PR в `main`.
4. Изучить [контракты](docs/CONTRACTS.md) и [план](docs/superpowers/plans/2026-11-07-smart-parking.md).

Все участники используют один и тот же [стартовый промпт для Claude Code](docs/SETUP_PROMPT.md). Он определяет участника по GitHub-аккаунту, настраивает среду и находит назначенное ТЗ. После запуска достаточно написать агенту **«проверь обновления на гитхаб»**: он перечитает свои issues, комментарии/ревью PR и обновления общих контрактов, затем продолжит актуальную работу.

## Окружение и сборка

Единый комплект: **Aurora SDK BT 5.2.1.200**, Docker Desktop, эмулятор ОС Аврора соответствующей версии. Установщик выбирается по ОС и архитектуре компьютера. Qt и инструментальную цепочку берём из SDK. Полный Platform SDK для разработки ОС не требуется.

Исходники проекта создаются мастером «Приложение Qt Quick для ОС Аврора». Первый вариант используем с qmake. Точные команды командной строки, идентификатор комплекта сборки и путь к RPM будут добавлены после первой проверенной сборки. Для BT используется `apptool`; команды `sfdk` относятся к другому варианту среды и не служат инструкцией для нашего комплекта.

На 7 ноября проверено: у Григория macOS ARM64, 8 ГБ памяти, примерно 77 ГиБ свободного диска. SDK и Docker не обнаружены в PATH и проверенных стандартных каталогах. На остальных компьютерах установка и запуск ещё не подтверждены.

Инструкция считается воспроизводимой только после проверки другим участником с чистого клона. Логи, версия SDK, архитектура пакета и снимок эмулятора прикладываются к PR каркаса.

## Данные и ограничения прототипа

Авторизация работает в явно обозначенном демонстрационном режиме, без реального SMS или письма. Оплата симулируется, реквизиты карты не собираются. Парковочные зоны и занятость вымышлены. Приложение не подтверждает наличие реального свободного места на улице.

SQLite сохраняет профиль, автомобили и парковочные сессии между запусками. Карта и локальные данные имеют разные зависимости: работа данных офлайн не доказывает наличие офлайн-подложки карты. Офлайн-карту заявляем только после проверки подготовленного локального источника MFW.
