# Оформление «Умной парковки» v0.1

Документ для #10. Владелец — Альберт (`Albe345`). Описывает общий вид приложения и контракт компонентов из `qml/design/`. Экраны соседей (`qml/account/`, `qml/parking/`) здесь только предлагаются, менять их файлы может только владелец.

**Статус проверки.** Свойства `Theme` сверены со справкой Silica ОС Аврора 5.2.1 (ссылка ниже). Сборка и запуск в SDK/эмуляторе **ещё не выполнены**. Все изображения в `docs/design/` — **макеты**, а не снимки устройства.

## 1. Принципы

1. **Спокойный городской интерфейс.** Нейтральный фон атмосферы, один сине-бирюзовый акцент, без декоративных градиентов и анимации.
2. **Три главных числа читаются сразу:** цена, свободные места, оставшееся время. Они набраны крупнее остального текста и стоят первыми в своём блоке.
3. **Одно основное действие на экране.** Оно стоит внизу содержимого (`Button` шириной `Theme.buttonWidthLarge`) или в `PullDownMenu`. Возврат — стандартный жест/стрелка `PageHeader`, отдельной кнопки «Назад» нет.
4. **Цвет никогда не единственный носитель смысла.** Каждый статус имеет подпись, а где возможно — и значок.
5. **Только нативные средства.** Шрифты, отступы, размеры и цвета берутся из `Theme`. HTML/React не переносим, сторонних QML-библиотек нет.
6. **Демо-режим виден.** Вход и оплата помечены «Демо» на самом экране, а не только в документации.

## 2. Цвет

Платформа сама меняет цвета под атмосферу и цветовую схему (`Theme.colorScheme`: `Theme.LightOnDark` или `Theme.DarkOnLight`). Поэтому базовые цвета не задаём числами, а берём из `Theme`. Единственный собственный цвет — акцент, и он тоже пропускается через `Theme.highlightFromColor(...)`, чтобы оставаться читаемым в обеих схемах.

| Роль | Значение | Где применяется |
|---|---|---|
| Основной текст, интерактивный | `Theme.primaryColor` | текст в `ListItem`, `BackgroundItem`, `Button` |
| Второстепенный, интерактивный | `Theme.secondaryColor` | вторая строка элемента списка |
| Основной, неинтерактивный | `Theme.highlightColor` | заголовки блоков, значения на талоне |
| Второстепенный, неинтерактивный | `Theme.secondaryHighlightColor` | подписи к значениям («Стоимость», «Осталось») |
| Нажатие | `Theme.highlightBackgroundColor` + `Theme.highlightBackgroundOpacity` | автоматически в `ListItem`/`BackgroundItem` |
| Ошибка | `Theme.errorColor` | только текст ошибки и её значок |
| Недоступно | `opacity: Theme.opacityLow` | занятое место, отключённая кнопка |
| **Акцент** | `AppStyle.accentColor` = `Theme.highlightFromColor("#1E9BB0", Theme.colorScheme)` | цена, «Свободно N», оставшееся время, метка «Демо» |
| Фон карточки | `Theme.rgba(Theme.highlightBackgroundColor, 0.12)` (`AppStyle.cardColor`) | карточка зоны, блок талона |

Базовый оттенок акцента `#1E9BB0` — сине-бирюзовый. Если на тёмной атмосфере эмулятора он сливается с системным `highlightColor`, оставляем только `Theme.highlightColor` и сообщаем об этом в #10. Решение принимается по снимку, не по догадке.

### Статусы

| Статус | Цвет | Подпись | Значок (проверить имя в SDK) |
|---|---|---|---|
| Свободно (> 3 мест) | акцент | «Свободно 12 из 40» | — |
| Мало мест (1–3) | `Theme.highlightColor` | «Осталось 2 места» | — |
| Мест нет | `Theme.secondaryColor`, `opacityLow` | «Мест нет» | — |
| Активная парковка | акцент | «Идёт парковка» | — |
| Истекла | `Theme.secondaryHighlightColor` | «Время истекло» | — |
| Ошибка | `Theme.errorColor` | текст из `message` сервиса | `image://theme/icon-m-warning` |
| Загрузка | — | «Загрузка…» | `BusyIndicator` |

Значки `image://theme/...` взяты из типового набора Silica. Каждое имя проверяется в SDK до использования; если значка нет, остаётся подпись.

## 3. Типографика

Шрифт системный: `Theme.fontFamily`, у заголовков `Theme.fontFamilyHeading`. Размеры только из `Theme`.

| Уровень | Размер | Пример |
|---|---|---|
| Таймер активной парковки | `Theme.fontSizeHuge` | `1:04:59` |
| Итоговая сумма (подтверждение) | `Theme.fontSizeExtraLarge` | `135 ₽` |
| Название зоны / заголовок блока | `Theme.fontSizeLarge` | «Демо-парковка Центр» |
| Основной текст, цена в карточке | `Theme.fontSizeMedium` | `180 ₽ / час` |
| Подписи, адрес, срок | `Theme.fontSizeSmall` | «Демонстрационный адрес 1» |
| Пометки «Демо», служебные | `Theme.fontSizeExtraSmall` | «Демо: оплата не списывается» |

Заголовок страницы — `PageHeader { title: ... }`. Длинный адрес и название переносятся (`wrapMode: Text.Wrap`); в однострочных элементах списка обрезаются через `truncationMode: TruncationMode.Fade`.

## 4. Отступы и размеры

| Что | Значение |
|---|---|
| Поля страницы слева и справа | `Theme.horizontalPageMargin` |
| Между блоками экрана | `Theme.paddingLarge` |
| Внутри карточки | `Theme.paddingMedium` |
| Между подписью и значением | `Theme.paddingSmall` |
| Строка списка (1 строка текста) | `Theme.itemSizeSmall` |
| Строка списка (2 строки) | `Theme.itemSizeMedium` |
| Основная кнопка | `Button { preferredWidth: Theme.buttonWidthLarge }`, по центру |
| Значки в строках | `Theme.iconSizeMedium` |

Ширина содержимого: `x: Theme.horizontalPageMargin; width: parent.width - 2 * x`. Всё содержимое страницы лежит в `SilicaFlickable` с `contentHeight: column.height + Theme.paddingLarge`, чтобы при открытой клавиатуре и крупном шрифте экран прокручивался, а кнопка не уезжала за край.

## 5. Компоненты `qml/design/`

Подключение из соседнего каталога: `import "../design"`. В каталоге лежит `qmldir`, синглтон `AppStyle` объявлен в нём.

### `AppStyle` (синглтон)

| Член | Тип | Назначение |
|---|---|---|
| `accentColor` | color | акцент, см. раздел 2 |
| `cardColor` | color | фон карточки |
| `currencySign` | string | `"₽"`; если в шрифте устройства нет глифа — `"руб."` |
| `formatKopecks(k)` | string | `13500` → `135 ₽`, `13505` → `135,05 ₽`, `1234567` → `12 345,67 ₽`; отрицательное, не целое или нечисло → `—` |
| `formatDuration(min)` | string | `45` → `45 мин`, `60` → `1 ч`, `90` → `1 ч 30 мин` |
| `formatRemaining(sec)` | string | `max(0, sec)`: `3899` → `1:04:59`, `309` → `05:09`, `0` → `0:00` |
| `formatLocalTime(utcSec)` | string | локальное время окончания `ЧЧ:ММ`; если не сегодня — `d MMMM, ЧЧ:ММ` |
| `freeSpacesText(free, capacity)` | string | «Свободно 12 из 40» / «Осталось 2 места» / «Мест нет», с правильным склонением |

Разряды разделяются неразрывным пробелом `U+00A0`. Деньги считаются только целыми копейками; деление на 100 делается целочисленно, `toFixed` для денег не используется.

### `PriceLabel.qml`

```qml
PriceLabel {
    amountKopecks: 13500     // property int, обязательно
    suffix: qsTr("/ час")    // property string, необязательно
}
```

| Член | Тип | Назначение |
|---|---|---|
| `amountKopecks` | int | сумма в целых копейках |
| `suffix` | string | текст после суммы, например «/ час» |
| `freeText` | string | что показать при `0`; по умолчанию «Бесплатно». На подтверждении и талоне задать `""`, тогда выводится `0 ₽` |

Наследует `Label`, поэтому `font.pixelSize`, `color`, `horizontalAlignment` задаются как у обычного `Label`. По умолчанию цвет — акцент, размер — `Theme.fontSizeMedium`. Сумма форматируется только через `AppStyle.formatKopecks`.

### `StatusPanel.qml`

```qml
StatusPanel {
    title: qsTr("Не удалось оплатить")
    message: result.message       // русский текст из сервиса
    busy: false
    onRetryRequested: page.retry()
}
```

| Член | Тип | Назначение |
|---|---|---|
| `title` | string | короткий заголовок состояния |
| `message` | string | пояснение, переносится по словам |
| `busy` | bool | `true` — крутится `BusyIndicator`, кнопка скрыта |
| `isError` | bool | `true` — заголовок цветом `Theme.errorColor` и значок предупреждения |
| `retryText` | string | надпись кнопки, по умолчанию «Повторить»; пустая строка прячет кнопку |
| `retryRequested()` | signal | нажата кнопка повтора |

Панель не вызывает сервисы сама: повтор выполняет страница-владелец.

## 6. Схемы пяти экранов

Обозначения: `[ Кнопка ]` — основное действие, `≡` — `PullDownMenu`, `‹` — стандартный возврат.

### 6.1 Вход и автомобиль (`qml/account/`, владелец Матвей)

```
┌────────────────────────────┐
│ Вход                 ДЕМО  │  PageHeader + метка «Демо»
│                            │
│ Телефон или e-mail         │  TextField, EnterKey → поле кода
│ ________________________   │
│ Код подтверждения          │
│ ________________________   │
│ Демо-код: 123456           │  fontSizeExtraSmall, акцент
│ SMS и письма не отправляются│
│                            │
│        [ Войти ]           │
└────────────────────────────┘
```
Следующий экран: «Мои автомобили» — список `ListItem` (номер `fontSizeMedium`, марка `secondaryColor`), пустое состояние `ViewPlaceholder` «Добавьте автомобиль», добавление через `≡ Добавить автомобиль`.

### 6.2 Карта и карточка зоны (`qml/parking/`, владелец Илья)

```
┌────────────────────────────┐
│ ≡ Демо-местоположение      │
│ ┌────────────────────────┐ │
│ │        КАРТА           │ │  верхние ~55 % высоты
│ │    ●       ●(выбрана)  │ │
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │  карточка зоны (см. макет)
│ │ Демо-парковка Центр    │ │  fontSizeLarge, highlightColor
│ │ Демонстрационный адрес │ │  fontSizeSmall, перенос
│ │ 180 ₽ / час   · 350 м  │ │  PriceLabel + расстояние
│ │ Свободно 12 из 40      │ │  акцент + подпись
│ │ Круглосуточно          │ │  secondaryHighlightColor
│ │     [ Выбрать место ]  │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```
Без координат строка расстояния не показывается (`distanceMeters = -1`). Нет GPS — `StatusPanel` «Местоположение недоступно» с кнопкой «Использовать демо-местоположение». В демо-режиме над картой метка «Демо-местоположение».

### 6.3 Подтверждение (`qml/booking/ConfirmationPage.qml`, #5)

```
┌────────────────────────────┐
│ ‹ Подтверждение            │
│ Зона    Демо-парковка Центр│  подпись secondaryHighlight,
│ Место   01                 │  значение highlightColor
│ Машина  А123ВС77           │
│ Время   45 мин             │
│ ────────────────────────── │
│ К оплате                   │
│ 135 ₽                      │  fontSizeExtraLarge, акцент
│ ДЕМО: оплата симулируется, │
│ данные карты не нужны      │
│      [ Оплатить (демо) ]   │  блокируется после нажатия

Во время запроса кнопка недоступна, под ней `BusyIndicator`. При ошибке — `StatusPanel` с `isError: true` и кнопкой «Повторить» (тот же `operationId`).

```
┌────────────────────────────┐
│ ≡ Продлить на 15/30/60 мин │
│ ‹ Парковка                 │
│ Идёт парковка              │  акцент
│ Осталось                   │
│ 1:04:59                    │  fontSizeHuge, акцент
│ до 23:45                   │  fontSizeSmall

Время вышло: таймер `0:00`, подпись «Время истекло» цветом `secondaryHighlightColor`, кнопка продления скрыта, предлагается «Найти парковку». Продление показывает новую цену и новый срок только из ответа `extend`.

## 8. Проверочный список экранов

| Случай | Ожидаемое поведение |
|---|---|
| Длинный адрес / название (≥ 80 символов) | переносится в карточке, в строке списка обрезается `Fade`, ничего не перекрывает кнопку |
| Крупная сумма `2147483647` коп. | `21 474 836,47 ₽`, переносится, если не влезает |
| Бесплатная зона | «Бесплатно» вместо `0 ₽` в тарифе; итог `0 ₽` на подтверждении |
| Нет GPS | `StatusPanel` + «Использовать демо-местоположение»; список работает |
| Нет сети / подложки карты | список зон и сохранённые данные доступны, сообщение о карте |
| Мест нет | статус «Мест нет», кнопка «Выбрать место» недоступна |
| Ошибка оплаты | текст из `message`, талон не показывается, «Повторить» с тем же ключом |
| Загрузка | `BusyIndicator`, основная кнопка недоступна |
| Длинный русский текст в кнопке | кнопка `buttonWidthLarge`, текст не обрезается без многоточия |
| Клавиатура | поля связаны через `EnterKey`, содержимое прокручивается над клавиатурой |
| Светлая/тёмная схема | только цвета `Theme` и акцент через `highlightFromColor` |
| Перезапуск | срок и остаток считаются из `expiresAtUtc`, а не из таймера |
