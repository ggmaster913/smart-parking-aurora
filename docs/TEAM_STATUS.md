## Решение по данным

PriceLabel.amountKopecks — QML real, значения только целые0..2^53−1. Это согласовано с пределом BookingService. Схема SQLite/денежные суммы остаются целочисленными.

Главный визуальный сценарий — карта и компактная панель; активная парковка показывает крупный срок и простую шкалу. Новые API/сервер/реальный платёж/ИИ-провайдер сейчас не обязательны.
