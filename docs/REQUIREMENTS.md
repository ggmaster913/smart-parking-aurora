# Требования и критерии сдачи

Источник: три файла организаторов, предоставленные Григорием 7 ноября 2026 года: описание задачи, требования к ПО и критерии оценки. Дополнительных указаний на момент старта нет. Шаблон презентации содержит 24 варианта и служебных слайда, а не требование сделать 24 слайда.

## Приоритеты

| Критерий | Вес | Что показываем как доказательство |
|---|---:|---|
| Решение конкурсного задания | 30% | Завершённые этапы и сквозной сценарий в Авроре |
| Качество решения | 25% | Воспроизводимая сборка, сохранность данных, корректный расчёт и обработка ошибок |
| Инновационность и креативность | 20% | Объяснимый выбор парковки по расстоянию, цене и доступности; устойчивость сценария без сервера. Эти свойства должны быть реализованы и показаны |
| Презентация и командная работа | 15% | Пятиминутный питч, вклад каждого, issues/PR и короткое демо |
| Потенциал использования | 10% | Понятная граница между демо и будущими API, реалистичный следующий шаг к пилоту |

Жюри ставит 1–10 по каждому критерию, считает взвешенную сумму и усредняет оценки. Отдельных численных весов этапов или гарантированных баллов за конкретную функцию в материалах нет. При равенстве итогов первым сравнивается решение конкурсной задачи.

## Этапы приложения

| Этап | Обязательные функции | Как принимаем |
|---|---|---|
| 1 | Вход по телефону/email, профиль, госномер и марка автомобиля, локальное хранение | Войти в демо-режиме, добавить машину, перезапустить, увидеть те же данные |
| 2 | Интерактивная карта симулированных зон, геолокация, ближайшие парковки, адрес, тариф, часы работы | Перемещать и масштабировать карту, выбрать маркер, сравнить список по расстоянию, проверить отказ GPS |
| 3 | Выбор места, расчёт стоимости, симуляция оплаты, электронный талон, активная парковка с таймером и продлением | Пройти сценарий целиком, повторить оплату двойным нажатием, перезапустить активную сессию, продлить |
| 4 | История, расходы, локальные уведомления, тёмная/светлая тема | Проверить каждую отдельно; частичный этап обозначить честно |
| Бонус | Реальный API парковочного сервиса | Начинать только после стабильных этапов и подготовки сдачи |

Стек: ОС Аврора, C++/Qt/QML, Аврора SDK/IDE, карта MFW. По актуальной официальной документации координаты получает Qt Positioning. Полноценный бэкенд не требуется: используем локальный JSON и SQLite. Макет в браузере не заменяет запуск приложения в Авроре.
