# Повтор запуска после ошибки

Хостовый регрессионный тест загружает настоящий `qml/SmartParking.qml`.
Минимальная заглушка Silica записывает маршруты без открытия дочерних страниц;
это не проверка рендеринга или API целевого SDK.

Сценарий: первоначальная ошибка → `stateChanged(ready=true)` → регистрация
сервисов по `retrySucceeded` → `servicesReady` → переход на вход. До исправления тест воспроизводит
`ReferenceError: accountService is not defined` и остаётся на странице ошибки.
Один перенос навигации на `retrySucceeded` недостаточен: QML-обработчик сигнала
может сработать до C++-слота. Поэтому готовность сервисов обозначается отдельным сигналом.

```sh
qmake /path/to/repo/tests/app/retry/retry-tests.pro
make
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software ./tst_startupretry
```

На хосте Qt5.15 допускается только предупреждение об устаревшем синтаксисе
Connections: этот синтаксис нужен целевой Qt5.6. Другие предупреждения проваливают тест.
Проверка в Aurora SDK и эмуляторе выполняется отдельно.
