# Запуск модуля парковок в эмуляторе (07.11.2026)

**Среда:** Windows 11 x64, Aurora SDK `5.2.1.200-mb2` (MB2, по решению координатора в #4 — проба;
целевая сборка BT не проверялась), комплект `AuroraOS-5.2.1.200-x86_64`, эмулятор
«Aurora OS эмулятор 5.2.1.200» (QEMU). Код ветки `feat/4-parking` @ `8df783a`.

**Стенд:** временная копия MapTemplate (`example`, BSD-3-Clause) вне репозитория. В ней
`main.cpp` создаёт SQLite в памяти (таблицы zones/spaces/sessions по контракту), импортирует
`data/parking-zones.json` через `ParkingCatalog::loadFile`, добавляет одну тестовую активную
сессию на `demo-center-01` сроком 90 с и регистрирует `parkingService`. Стартовая страница —
`qml/parking/ParkingMapPage.qml`. `.desktop`: `Permissions=Internet;Location`.
Это не каркас приложения из #1 и не его замена.

**Результаты IDE:** сборка x86_64 Debug с `-DQT_SQL_LIB -DQT_POSITIONING_LIB` — успешно; RPM
подписан ключом разработчика; `sfdk … deploy` — `Installation successful`; при запуске система
запросила разрешения «Геолокация» и «Интернет».

## Масштаб и отказ сети (08.11.2026, 01:05–01:10 МСК)

`ParkingMapPage.qml`: кнопки «+/−» меняют свойство `MfwMap.zoomLevel` на целый уровень в границах
`minimumZoomLevel`/`maximumZoomLevel` ([документация MfwMap](https://developer.auroraos.ru/doc/extended/mfw/mfw_map/all_classes/mfwmap#zoomLevel-prop));
`setZoomLevel` не слот, поэтому из QML используется запись свойства. Щипок в эмуляторе мышью не
воспроизводится, кнопки его дублируют. Границы заданы явно (3–19, максимальный уровень растровых
тайлов OSM): с границами по умолчанию кнопка «+» в эмуляторе не срабатывала.

Стенд собран из CLI `sfdk -c target=AuroraOS-5.2.1.200-x86_64 build`, RPM `0.1-4` подписан тестовым
ключом SDK (`regular`), `sfdk deploy --sdk` — `Installation successful`; `qmllint` — без ошибок.

**Наблюдение по отказу сети:** MfwMap не сообщает об ошибке загрузки тайлов, поэтому панель
«Подложка карты недоступна» не появляется — пользователь видит размытую карту из кеша. Отдельный
индикатор сети в объём #4 не входит; вопрос передан координатору.
